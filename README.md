# cnc_geo_guessr
C&amp;C Geoguessr Game

This is a simple GeoGuessr-style game for Red Alert 2 Yuri's Revenge, vibed-coded using Claude.

It contains two map categories:
- Red Alert 2 Yuri's Revenge (RA2YR)
- Mental Omega (mod for RA2YR)
